# XErp 产品使用与验收手册（UAT Guide）

> 版本：v0.x · 适用 commit ≥ `28cfd73` · 全部示例数据已预先验算，可直接照抄
> 验收方式：在 WorkBuddy 对话中让 AI 调用 MCP 工具（XErp 连接器已配置），每步给出「你对 AI 说的话」「预期返回」「通过标准」
> 原则：**验收使用独立账套**，不污染演示账套与 OPC 账套；所有金额均为字符串（decimal-string 约定）
