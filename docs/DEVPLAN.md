# XErp 开发计划（可落地版）

> 依据：`DESIGN.md` v0.1 · 2026-08-27
> 原则：每个任务有唯一 ID、明确产出物、可验证的 DoD（完成的定义）、依赖关系与估时；AI 结对开发，任务粒度 = 一次可独立提交的 PR。

---

## 0. 总览

| 阶段 | 周期 | 目标 | 出口门（Gate） |
|---|---|---|---|
| **P0 凭证 PoC** | 4 周（~18 人日） | 对话建凭证→审批→过账→查余额最小闭环 + Drill 建套 | G4: 新环境 30 分钟从零到第一张凭证，v0.1 发布 |
| P1 GL 内核 GA | +6-8 周 | 三表+结转+多账套+权限审计+A2UI 界面 | G5: OPC 真实账套连续跑 1 个月 |
| P2 业务接入 | +8 周 | 应收应付适配器、发票 OCR、银行对账 | G6: 采购→发票→凭证→付款全链路 |
| P3 无人值守 | +6 周 | 关账 Agent、异常侦测、L3 自治 | G7: 月结 ≤2 小时（人工抽检） |
| P4 开源生态 | 持续 | GitHub 公开、插件市场、社区 | 外部 PR 出现 |

**仓库结构（monorepo，P0-01 建立）**
```
ledgeros/
├── kernel/        # Python: FastAPI + SQLAlchemy + PG  记账内核/状态机/事件账本
├── mcp-server/    # MCP Tools/Skills/Resources 暴露层
├── web/           # A2UI 渲染前端（P0 简化兜底，P1 正式）
├── skills/        # SKILL.md（WorkBuddy/Agent 客户端分发单元）
├── deploy/        # docker-compose.yml / .env.example
├── docs/adr/      # 架构决策记录（ADR-001 起）
└── tests/         # 内核规则测试必须 100% 覆盖不变量
```

**统一工作流（每个任务）**：AI 实现 → pytest 过 DoD → self-review → commit（简体中文提交信息）→ 任务表勾销。
